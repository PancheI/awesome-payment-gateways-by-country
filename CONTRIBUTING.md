# Contribution Guidelines

Thanks for helping keep this list accurate.

## Adding an entry

- The provider must be a payment gateway, acquirer, or merchant of record that a developer can actually sign up for and integrate. A bank product with no public API or sign-up does not count.
- Link to the provider's official docs, pricing, or supported-countries page, not a blog post, an affiliate page, or a third-party review.
- Put the entry in the country section where the provider settles money for local merchants. A provider that serves many countries belongs in Global Providers instead.
- Use this format and keep the section in alphabetical order:

  `- [Name](https://link) - One-sentence description. Fees: concise published fee.`

- State only fees the provider publishes on the page you link to. If a rate is not on that page, leave the fee out.
- Do not start the description with the provider's own name.
- One provider per pull request, unless the PR updates a whole section.

## Updating an entry

Fees and country availability change all the time. If a rate changed, a provider stopped serving a country, or a link broke, open a pull request with the link to the official page that shows the change.
